# Dev / TL 全生命周期标准人天基准表 v5.0（讨论稿）

- 状态：讨论稿
- 日期：2026-09-02
- 适用范围：Developer / Tech Lead 实际承担的软件交付工作
- 计量方式：一行 Task 对应一个基础工作单元，不使用数量字段
- 人天单位：PD

> 本文档是对 Dev / TL 全生命周期基准的新版讨论稿，不替代当前 SOW v1.3 的
> [任务分类与开发交付人天标准](SOW任务分类与开发交付人天标准_v1.3.md)，也不是当前插件的计算权威。
> 如需进入正式使用，必须另行评审并同步到 `sow-template.xlsx`、合同、Fixture、测试和发布元数据。

`-` 表示该工作类型不适用对应工作模式。“计量单位”用于限定一行 Task 能够表达的完整交付边界，
不作为数量参数参与计算。
