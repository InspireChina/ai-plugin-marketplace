# I6.3：Task 备注展示分类判断原因

用户要求 `02-任务清单` 的备注列包含非新建工作方式的判断原因、非 M 复杂度的判断原因，以及待确认项。I6.2 的普通空备注规则据此细化；Story 备注规则保持。

## 实现范围

投影读取同版 `Task.classification_basis` 的 `fields/rationale`，只展示适用维度及当前值。相同正文只写一次，合并适用标签；不分析或摘要原文，不复制证据 ID。新建/M 不额外展示原因，未知工作方式沿原问题机制处理。已有合法分类必须带依据的机械校验保持，原因正确性仍由 Agent 负责。

open 问题及当前处理保持 G 的首段，以“待确认：”开头；原因、必要责任说明或安全别名原名接在其后。只有原因时执行普通校验，有问题时显示待确认。原因不回写模型 `notes`；G 映射到 `classification_basis`，物理容量或非法字符错误指向该字段。详见 [D06](../../design/detailed/D06-excel-projection-and-delivery.md) 和 [联合生成规则](../../../references/generate-slices.md)。
