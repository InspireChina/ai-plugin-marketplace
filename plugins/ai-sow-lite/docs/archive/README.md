# 历史档案

这里保存开发期间的方案、验证事实和原始性能指标。它们记录当时的版本与判断，不是当前操作指引或尚待执行的任务。使用说明见 [插件 README](../../README.md)，当前状态见 [验证摘要](../validation/README.md)。

## 分类

| 目录 | 内容 |
|---|---|
| [planning](planning/REVIEW.md) | 实现前 Review、详细设计路线图、开发依赖图、资料吸收和 E2E 修复方案 |
| [implementation](implementation/README.md) | P00—P05 开发任务和实施依赖 |
| [validation](validation/I11-estimation-relevance.md) | I1—I11、两期 E2E、宿主与性能记录，以及相应原始指标 |

当前领域/架构设计仍在 [design](../design/README.md)。运行时只使用自身代码、合同、Skill 与专业参考，不需要阅读本档案。

I1—I7 的计划内开发和后续 I8—I11 的规则调整已完成各自记录的实施与验证；性能目标及平台覆盖限制仍开放。历史文档中的“下一步”“待实施”“待验证”应结合其日期和对应后续记录理解，不能作为当前发布阻塞清单。

## 旧样本快照

早期 `docs/validation/samples/three-scope/` 的 13 份候选、来源和项目快照已从当前文档目录移除。它们来自 I1.1，未生成 Excel 或应用 current，也不是当前测试必需输入。原字节及当时重放说明可从 Git 提交 `08f01ef` 下同一路径恢复；不使用当前模板来宣称旧快照仍兼容。

活跃测试输入、期望和复用支持代码仍保留在插件 `tests/`。此次没有删除实际客户项目、现有交付版本或性能原始数据。

## 追溯约定

归档仅调整目录和文档链接；指标 JSON 保持原字节，场景台账只更新证据路径，不改变状态和结论。旧失败、有限修正和未验证项均保留。原先按开发轮次追加的 CHANGELOG 可从 `08f01ef` 查阅，当前版本说明按用户可见能力重写。
