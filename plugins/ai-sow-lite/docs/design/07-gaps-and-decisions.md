# 07 · 已定规则与剩余验证事项

[返回总览](README.md)

本页保留已定产品规则与 G01—G17 验证事项。单人串行、金额交由原模板且计算口径不变已确认；校验原型/A2 说明的后续窄改以 D06 为准；有限编辑构造接口已补齐，见 [13 自检结论与已定边界](13-self-review-and-decisions.md)。

## 1. 已确定

- 两个入口 generate / clarify，业务文件共享、运行流程独立。
- 开场固定完成确定新旧项目、收集必要输入两件事。PRD、高阶设计必需；旧项目另需往期 SOW；原型可选；已有类型和材料直接复用。
- 分析全部输入后，仅澄清和确认输入相关的业务、技术、交付事实、歧义、冲突和决定，默认首轮加最多一轮补问。基础不足不推进；不增加分析摘要、拆解结果、分类或出稿审批。
- 输入除原型外只支持可读文本（默认 Markdown）与 `.xlsx`；PDF/DOCX、扫描件及其他格式暂不支持，不安排 OCR 或自动转换。
- 往期 SOW 直接构建估算 as-is，其余项目材料构建 to-be，模板独立提供规则；本期负责的 gap 形成骨架。历史按可识别的条目/层级/说明建轻量索引，不强求 AC、类型或实例规格。无候选默认新建；候选实例未明则新建+待确认；实例适用明确才按变化判断或排除已满足项，未读/失败与描述粗略分开。
- 信息补足后先搭 gap 骨架，再按业务切片联合生成并合并检查，不逐片审批。
- 从 PRD、原型和 HLD 主动识别业务、技术及交付需求，组织为相应 Epic/Feature/Story。独立 NFR 公共能力与业务接入分别界定、公共建设只计一次；迁移和上线准备同样属于范围识别责任。
- 主动识别不等于自动补方案：非业务工作也要有来源、本期责任和交付依据。AC 可来自 HLD 或交付材料，未知指标、方案和责任仍按现有问答及留空规则处理；不强制三个顶层 Epic 或给每项 NFR 单建能力。
- 不猜前提、方案或缺失事实。复杂度无法判断直接按 M 出稿并留待确认，不反复找定档证据；其他后期局部缺依据字段留空，不能用大量空白掩盖基本资料不足。
- Story 专业内容仅标题、来源 AC、备注；Task 为名称、工作类型名称、工作方式、复杂度、集成类型、备注。
- AC 表达验收结果，Task 表达实施工作；同片联合形成，不机械逐条转换或强制每个 Task 关联 AC。实施对象只作为分析方法，首版不增加独立实体、清单或阶段。
- 原件保留，输入区分物理格式、材料类型和使用用途；原型按关联资源包分析，未读取或未观察不等于不存在。同一物理材料的多个用途不自动改变其权威边界。
- 轻量索引与分析结果按需提取，区分来源事实、观察、判断与用户决定，保留版本、定位和覆盖限制。不引入全量 IR 转换门槛；字段、格式、复用及失效规则在 D02/D03 详细设计中确定。
- 使用已复制的 [sow-template.xlsx](../../assets/sow-template.xlsx)，`90-估算标准` 是标准来源；agent 只做定性匹配，人天由模板处理。
- SIT 按标准表的系统集成工作类型判定，Story 含任意适用 Task 即适用；SIT/UAT 都由受保护公式汇总。UAT 按 Task 工作类型标准判定。直接交付系统功能的类型适用；Story 含任意适用 Task 即适用，由受保护公式计算，agent 和用户不填写该字段。
- Clarify 根据输入和答复讨论具体方案，确认后在限定对象和回查范围内更新；每次成功直接返回文件，无后置定稿。
- D04B 统一各类环路的有限集合、批量处理、追加上限和无进展出口，计数跨恢复保留；不因新路径一直出现而无限继续。用时/token 埋点独立用于流程观察和优化，不增加预算审批。
- 自制 draft 可作为辅助输入分析，不能据此豁免必需材料；任意手改 Excel 无损回导不作为当前目标。
- ai-sow 已跑通；Lite 参考其依赖安装、Python 技术栈、文件与 Excel 操作证据，重点验证差异和真实未知能力。源码迁入后仍须自包含，不继承旧专业流程或为未改变能力重复做基础选型实验。

## 4. 首个贯穿样例

使用必需材料齐备的新项目：PRD 有业务及 NFR 要求，HLD 明确一项公共能力和迁移/上线安排；分析后补充一轮关键责任事实，形成三类范围的骨架。公共建设与两个业务接入分别拆解、只计一次公共建设，交付 Story 不遗漏；复杂度无法识别按 M 出稿并附待确认；其他无默认规则的分类缺值仍留空。Excel 可写字段保留已知内容及真实空值，业务待确认在同版说明列清楚；模板的金额结果不由插件干预。

在新会话运行 clarify，用户答复该项，讨论并确认局部方案，再把四项分类中对应字段补入，由模板得到更新结果。另用老项目缺往期 SOW、仅有 draft + tech note、多轮回答仍不足、Task 类型未明但原 SIT/UAT 公式保留、非集成 Task 集成类型留空及保存中断验证异常出口。

当前已准备独立手填模板，删除隐藏辅助列，将复杂度细则全部展开、参数直接保存在汇总页，完成 UAT 标准、公式与保护调整，并用 LibreOffice 验证估算与汇总。agent 内部辅助结构及其 Excel 写入适配仍需单独设计。Microsoft Excel 已验证正常打开、保存后重开、UAT 基本计算和禁止手改；计算列元数据兼容问题已修复并加入回归。Skill、生成器和完整输出计算尚未实现，不能把模板单项验证等同于插件端到端运行通过。
